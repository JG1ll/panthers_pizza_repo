# Panther's Pizza Website

A modern, responsive website for Panther's Pizza - a Neapolitan-inspired pizzeria in Sheung Wan, Hong Kong.

## 🍕 About

Panther's Pizza is opening its doors in 2025 in the heart of Sheung Wan, Hong Kong. This website showcases our handcrafted pizzas with light, flavorful crusts, fresh salads, crispy chicken wings, and popular items like truffle fries.

## 🚀 Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Interactive Navigation**: Single-page application with smooth transitions
- **Menu Showcase**: Beautiful display of our menu items with high-quality images
- **Online Ordering**: Integration with Foodpanda for seamless ordering
- **Contact Information**: Complete location, hours, and contact details
- **Social Media Integration**: Links to Facebook and Instagram

## 🛠 Technologies Used

- **HTML5**: Semantic markup
- **CSS3**: Modern styling with Flexbox and Grid
- **JavaScript**: Interactive functionality
- **Tailwind CSS**: Utility-first CSS framework (via CDN)
- **Google Fonts**: Typography (Poppins, Luckiest Guy, Caveat)

## 🚀 Deployment

This is a static website that can be deployed on any static hosting service:

### Cloudflare Pages (Recommended)

1. Push code to GitHub/GitLab
2. Connect repository to Cloudflare Pages
3. Set build settings:
   - Build command: (leave blank)
   - Build output directory: `/`
   - Root directory: `/`
4. Deploy and connect custom domain

### Other Options

- Netlify
- Vercel
- GitHub Pages
- Any static hosting service
